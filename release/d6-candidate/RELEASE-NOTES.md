# ALICA Community DSH D6 Independent Acceptance

D6 independently qualifies the exact accepted D5 candidate bytes; it does not silently alter runtime bytes. Two separate clean public hosted operators must pass the same closed matrix, with one obtaining application artifacts online and one installing from the complete checksum-bound offline bundle after application-network denial.

Publication requires both authenticated QA10 runs, ten healthy services, no-op reinstall, alert, encrypted off-host backup, restart convergence, no private or central runtime dependency, immutable evidence and zero unresolved P0/P1 acceptance blockers.

The D6 evidence is a publication decision for the exact qualified bytes and frozen `dsh-minimal/v1` boundary. It is not a claim of multi-node HA, paid support/SLA, managed hosting rights, `dsh-standard/v1`, automatic repair, arm64 or non-Debian support.
