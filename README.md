# Alica-DSH

Canonical distribution repository for **ALICA Community DSH**.

The transactional D2 clean-install implementation is maintained in `BartSchuster22/UNIFY` on branch `feature/unify-functionality-qa10`. Formal public distribution remains gated on immutable OCI publication and isolated clean-host acceptance.

This repository was initialized for DSH release automation and must not contain private signing keys, registry tokens, generated installation credentials, or unreviewed release claims.
